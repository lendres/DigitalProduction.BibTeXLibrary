# BibTeXLibrary
A utility library for editing BibTeX files.  Written in C#, it provides features for reading, writing, and editing a bibliography file.

See the [wiki](https://github.com/lendres/DigitalProduction.BibTeXLibrary/wiki) for more information.

## Requirements

Version 0.10.0 requires .NET 10 and DigitalProduction.Net 0.13.0. Build with the .NET 10 SDK and its default C# 14 language version.

The .NET 9 releases are no longer maintained.
